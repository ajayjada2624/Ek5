# EK5 Game Official Portal (ek5.co.in)

Welcome to the official GitHub repository for the **EK5 Game** download and informational website (`ek5.co.in`). This repository contains all the responsive, SEO-optimized HTML pages for the EK5 gaming platform.

## 🚀 Features
* **Modern Design:** Dark mode layout with Golden (`#fbbf24`) and Red (`#dc2626`) color accents.
* **Responsive Layout:** Fully optimized for mobile phones, tablets, and desktop screens.
* **Fast & Lightweight:** Built with clean HTML5 and CSS3 without heavy frameworks.
* **SEO Optimized:** Complete with meta tags, Open Graph tags, Rich Snippets (Schema.org), and a sitemap.

## 📁 Repository Structure
* `index.html` - Homepage with app download links, game features, and FAQs.
* `about-us.html` - Information about the EK5 platform.
* `contact-us.html` - Support page with a contact form and details.
* `ek5-upi-withdrawal-guide.html` - Step-by-step guide for UPI deposits and withdrawals.
* `disclaimer.html` - Legal and responsible gaming disclaimers.
* `privacy-policy.html` - User data privacy and protection policies.
* `sitemap.xml` - XML Sitemap for search engine indexing.
* `robots.txt` - Search engine crawler directives.
